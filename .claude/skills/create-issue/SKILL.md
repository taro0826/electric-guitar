# issueを作成する

## ルール

- **タイトル**: 言い切りの用言止めにする（例: 「距離に応じて音程が変わる」）。
- **本文**: [.github/ISSUE_TEMPLATE/default.md](../../../.github/ISSUE_TEMPLATE/default.md) の構成で、しっかり書く。
  - 先頭の `---` で囲まれた部分（GitHub用の設定）は本文に含めない。
  - `{issue名}` はタイトルに置き換える。
  - 各項目の説明文は内容に置き換える。
  - 冒頭の「※」の注意書きと、使わない（Opt.）項目は削除する。
- **ラベル**: 既存のラベル（`gh label list`）から、次の2種類を付ける。
  - 種類（「機能追加」「組み立て」など）: 該当するものを1つ以上。
  - 優先度: 次のどれか1つだけ。迷ったら「ぜひやりたい！」にする。

    | ラベル | 基準 |
    | --- | --- |
    | やらないといけない | 他の作業がこれを待っている、または演奏できない原因になっている |
    | ぜひやりたい！ | 次に取り組む予定のもの |
    | あとでいいかな？ | あるとよいが急がないもの |
- **マイルストーン**: 既存のマイルストーンから適切なものを選ぶ（`gh api repos/{owner}/{repo}/milestones`）。該当がなければ付けない。
- **担当者**: 指定がなければ自分（`@me`）にする。

## 手順

```bash
gh issue create --title "<タイトル>" --body-file <本文ファイル> --label "<種類>" --label "<優先度>" --milestone "<マイルストーン>" --assignee @me
```
